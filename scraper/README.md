# Polite Book Scraper (Python Lane)

## Target Classification
- **Target Site:** Books to Scrape (https://books.toscrape.com)
- **Purpose:** Public practice sandbox designed explicitly for web scraping practice.
- **Scope:** First 3 catalogue pages (~60 book detail pages).
- **Data Collected:** Title, product URL, price, availability, rating, description, source page, and fetch timestamp.
- **Robots.txt Check:** Requested `https://books.toscrape.com/robots.txt` (result: no robots file found).
- **Ethics Statement:** I will not reuse this code on another site without checking its rules and terms first.
